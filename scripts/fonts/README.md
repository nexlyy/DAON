# Fraunces

`Fraunces-Medium.ttf` is the weight the site header uses, kept here so the logo
exports can be regenerated without a network call. Downloaded from Google Fonts,
where it is published under the SIL Open Font License 1.1:

- https://fonts.google.com/specimen/Fraunces
- https://github.com/undercasetype/Fraunces

The site itself loads Fraunces from Google Fonts, not from this file.
