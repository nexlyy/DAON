# 한국어 텍스트 수정 안내

사이트의 한국어 문장은 세 개의 파일에 있습니다. 코드는 건드리지 않고 이 파일들만 고치면 됩니다.

| 파일 | 내용 |
| --- | --- |
| `src/content/menu.ko.json` | 메뉴: 분류 이름, 메뉴 이름과 설명 (번호별) |
| `src/i18n/locales/ko.json` | 사이트의 나머지 문장: 버튼, 제목, 예약 화면, 안내 문구 |
| `src/content/privacy.json` | 개인정보 처리방침 (`"ko"` 부분만) |

## 1. 사이트를 켜서 보면서 고치기

VS Code 아래쪽 터미널에서 한 번 실행합니다.

```bash
npm run dev
```

브라우저에서 **http://localhost:5173** 을 열고 오른쪽 위 언어를 **한국어** 로 바꿉니다.
파일을 저장(`Ctrl+S`)하면 브라우저 화면이 바로 바뀝니다.

## 2. 메뉴 고치기 — `src/content/menu.ko.json`

메뉴는 인쇄된 메뉴판의 번호 순서대로 있습니다. `Ctrl+F` 로 번호나 이름을 찾으세요.

```json
"03": {
  "_참고": "Bulgogi",
  "name": "소불고기 한상정식",
  "description": "한상차림에는 야채쌈과 소스 그리고 밥과 탕이 함께 서비스합니다."
},
```

- **`name`** 과 **`description`** 의 따옴표 안 글자만 고치세요.
- **`_참고`** 는 어떤 메뉴인지 알려 주는 영어 이름입니다. 고쳐도 사이트에는 바뀌는 것이 없습니다.
- 번호(`"03"`)와 `name`, `description` 같은 영어 단어는 그대로 두세요.

## 3. 사이트 문장 고치기 — `src/i18n/locales/ko.json`

```json
"phoneLimit": "이 전화번호로는 ... {phone}로 전화 주시면 도와드리겠습니다.",
```

- 콜론(`:`) **오른쪽** 따옴표 안의 글자만 고치세요. 왼쪽 영어 이름은 그대로 두세요.
- `{phone}`, `{time}`, `{guests}` 처럼 **중괄호 안의 영어 단어는 지우거나 바꾸지 마세요.** 사이트가 그 자리에 전화번호, 시간, 인원 수를 넣습니다. 문장 안에서 위치는 옮겨도 됩니다.

## 꼭 지켜야 할 규칙

1. 글자는 항상 **큰따옴표 `"` 사이** 에 있어야 합니다.
2. 문장 안에 큰따옴표를 쓰고 싶으면 `“ ”` 또는 `‘ ’` 를 쓰세요. 그냥 `"` 를 쓰면 파일이 깨집니다.
3. 줄 끝의 **쉼표 `,`** 를 지우지 마세요. (각 묶음의 마지막 줄에는 쉼표가 없습니다.)
4. 줄바꿈은 넣지 말고 한 줄로 이어 쓰세요. 화면에서는 자동으로 줄이 바뀝니다.

VS Code에서 빨간 물결 밑줄이 보이면 그 근처의 따옴표나 쉼표가 빠진 것입니다.

## 4. 다 고친 뒤 확인하기

```bash
npm run check:ko
```

- **`모든 확인 완료 — 문제가 없습니다.`** 가 나오면 끝입니다.
- **`오류`** 가 나오면 줄 번호와 이유가 함께 나옵니다. 그 부분을 고치고 다시 실행하세요.

실제 사이트(daon.pl)에 올리는 작업은 이 노트북을 준비한 직원이 합니다. 수정이 끝나면 알려 주세요.
